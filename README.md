# Resume Website – Om Pagar

## 📌 Project Overview

This project is a simple and modern **Resume Website** created using **HTML and CSS**.

The webpage presents personal information, education, technical skills, and contact details in a clean and professional layout.

---

## 🛠️ Technologies Used

* **HTML5** – Used to create the structure of the resume.
* **CSS3** – Used for styling, layout, colors, spacing, and responsiveness.

## 🚀 How to Run

1. Download or clone the project.
2. Keep `index.html` and `assignment1.css` in the **same folder**.
3. Open the folder in **VS Code**.
4. Open `index.html`.
5. Right-click on the file and select **Open with Live Server**, or open the HTML file directly in a browser.

---

## 📱 Responsive Design

The website automatically adjusts its layout for smaller screens using a CSS media query:

```css
@media (max-width: 768px)
```

This makes the resume easier to view on mobile devices and tablets.
